## 新增转换代理的部署边界

`akb.preview_broker` 仅依赖 Python 标准库。宿主机通过 `zhixu-preview.service` 管理，私有临时目录只允许服务操作员访问，socket 仅供 API UID/GID 10001 访问。请求不接受 URL、主机文件路径、命令或认证信息；限定格式、100 MiB 原件、两条并发请求、读写超时和磁盘余量。实际转换继续使用固定摘要镜像、无网络、只读根目录、非 root 用户、宏禁用、CPU/内存/PID/输出大小限制。服务端清理原件后才返回 PDF。

API 容器只读挂载 socket 所在目录，并设置 `AKB_PREVIEW_SOCKET`；禁止挂载 Docker socket。普通上传上限仍为 2 GiB，Office 预览上限为 100 MiB。尚需验证 Linux 权限、systemd 重启恢复和实际校园预览。
