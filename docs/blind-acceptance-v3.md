## 局限与新发现

- 盲测为同一操作系统下的目录与任务约束，不是独立 OS 沙箱；标准答案未提供给模型，不据此声称技术上绝无访问可能。本轮为单一人物与固定表单，不能外推通用准确率。
- 受控事迹当前表述偏机械，不等于自然、成熟的申报材料。它避免自由改写引入新事实，但不是自由文稿的通用语义验证器。
- 任意网页的字段含义仍需 Agent 正确读取；本轮网页使用固定公开契约。模型端没有网页已保存值读取接口，验收方独立读取服务端实际保存文件核对，不能将模型自述“双向校验”视为任意站点回读已解决。
- Word 模板只有 10 个占位符，全部替换并保留人工备注；不是 23 个网页字段全部作为独立字段出现在 Word。模型增量报告对未覆盖字段的列举不完整，独立验收以原模板与逐段比较为准。
- 共用目录的同步、一致性与人工覆盖保护通过；**摘要可读性为 PARTIAL**。现有规则摘录会将 `8.24`、DOI 等按句点拆开，出现残句或截断，不能以目录同步成功声称摘要质量也通过。此问题不影响本轮基于完整证据计算的数值，仍需后续修正。
- 首轮语义提交出现 3 次引文/时间校验 422，由模型重读后自行修正。目录 JSON 约 319 KB，单个完整草稿响应约 298 KB，存在上下文体积与耗时成本。
- 初始 5 份、增量 1 份材料为 partial 解析；本轮关键证据已核对，不覆盖复杂 Office、手写 OCR、2 GiB 压测、多人并发或生产部署。
