# Pagebeak 通用身份兼容版本上线

2026-11-05 已将 `0.13.6-identity` 发布到 [线上开始页](https://zhixu.110-lab.cn/start)。前端 revision 为 `zhixu-32e6ba782aff`，数据库版本为 `0027`。共享 WorkBuddy 助理包保持 `0.13.5`，既有用户无需重新安装、重新登录或重新授权。

**本次上线的是兼容模式。** 当前没有真实 WorkBuddy 第三方应用或其他身份提供方凭据，`identity_required` 保持 false，没有向教师增加注册、账号绑定或学校身份验证步骤，也没有把匿名空间冒充已验证的平台账号。外部账号复用的代码已发布，但真实账号授权和强制身份模式尚未启用。

## 用户侧变化

原来的空间、Cookie、MCP 客户端注册与令牌继续有效。文件、目录、人工修改和初始化回答保留。已连接用户可以在开始页“已连接的助手”查看和撤销单个客户端。没有配置外部身份提供方时，不显示要求绑定账号的提示。

已打开的旧页面继续使用既有接口；新发布目录保留旧页面引用的散列资源，避免缓存页面加载旧 JS/CSS 时出现 404。缓存的新页面也能读取旧后端的开始页响应，用于兼容回退。没有强制清理浏览器缓存或自动刷新用户正在编辑的页面。

| 文件空间会话 | 升级前的原生文件令牌仍有效；浏览器点击“打开我的资料”直接进入同一文件空间 |
| 网页目录 | 独立浏览器配置使用原合成验收空间，正常看到既有 Word 文件与知识目录 |
| 通用协议客户端 | 正式域名接受反向域名形式的原生回调，完成 OAuth PKCE 和本人空间核对；只读授权不能写入，单独撤销不影响既有连接 |
| 检索与填表 | 既有合成原文和目录可检索；128000 元换算为 12.8 万元，未知电话留空，引用与填写草稿校验通过 |

这些验证使用此前明确标记的合成验收空间，没有接管用户浏览器中的私人资料。浏览器检查使用隔离的 Playwright 配置，实际访问正式 HTTPS 域名并保持证书校验；不是合成身份服务页面截图。当前用户窗口的 CUA 读取超时，未据此宣称验证了该窗口中的 WorkBuddy 原生任务。

填写验证是已有合成资料的协议回归，不是新一轮真实模型盲测，也没有对外提交表单。

## 切换过程中的异常

本次**不能声称全程零中断**。监测共记录 7546 次健康和已授权目录请求，其中有 4 个短暂 502 响应；HTTPS 入口日志确认当时无法连接正在重建的内部代理 `127.0.0.1:5879`。旧入口禁用了管理接口，初次启用受限热更新需要替换该代理。

首次发布脚本还将 `agent_jobs.state` 错写为 `agent_jobs.status`，在排空检查时触发自动回退。兼容回退实际成功，未回滚或覆盖数据库。随后将检查修正为后台解析任务，先在实际数据库执行验证，再通过已启用的 Unix socket 管理接口热更新路由，完成新版切换。成功的第二次热切换期间，监测未新增错误。

现在的代理管理接口只监听容器内 Unix socket，没有增加公网管理端口。后续发布可以先在旁路启动新版、验证原会话，再通过该接口平滑切换；不再依赖重建代理来改后端地址。

## 尚未开启的部分

真实外部账号复用需要平台应用凭据和用户首次授权。配置后应先让已有空间证明访问权并显式绑定，完成真实客户端验证，再决定是否开启身份必需模式。不能为了减少点击，将未经验证的客户端名称、昵称、邮箱或自报 ID 当作租户身份。
