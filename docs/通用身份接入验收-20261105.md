## 浏览器链路的真实范围

本地启动了独立合成身份服务，使用 HTTPS、授权码、PKCE、签名 ID Token 与 JWKS。Pagebeak 后端通过显式信任合成证书完成 HTTPS 校验，没有关闭服务端证书验证。浏览器对该本地自签名证书进行了测试放行，不能据此宣称验证了正式域名的证书链。

浏览器使用完整构建前端，账号授权与 MCP 调用走实际 HTTP 服务。两份独立浏览器配置分别持有自己的登录 Cookie 和客户端授权。底层 Cloudreve 账号开通在本次隔离测试中使用替身；没有在正式服务器上创建账号，也没有重新验证云盘上传、Office 解析、WeKnora 整理和模型填写整条业务链路。

协议客户端名称为验收标识，不代表已经在两个真实 Agent 产品中完成安装。WorkBuddy 适配器使用符合官方字段格式的模拟服务响应，验证服务端交换结果与绑定逻辑；真实 WorkBuddy 应用授权仍需开发者应用凭据。
