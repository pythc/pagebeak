## 账号和凭据边界

`GET /v1/native/start` 及三个 POST 路由 `/setup`、`/package`、`/launch` 以 `X-Cloudreve-Token` 调用文件服务核验当前身份。前端不发送知识库 Cookie，并传当前文件账号 ID；服务端与请求前后均检查账号，异步读取响应后再次检查，丢弃切换账号后的旧响应。

读取不签发凭据。生成接入包或安装任务时，仅创建不返回给浏览器的 20 分钟内部签发凭据，支撑已有 15 分钟一次性接入码流程。原通用知识库 API 的鉴权和来源限制保持原状。新路由沿用限流，明确拒绝其他来源。

首次关联通过当前文件账号的独立登录建立后台同步会话，避免后台刷新影响浏览器会话。密码不持久化，独立文件服务会话令牌保存于私有 0600 文件；新用户以稳定文件账号 ID 建立独立知识库，不推断姓名、职业等个人事实。已存在的绑定不得覆盖，文件写入失败会清理半成品并回滚创建。
