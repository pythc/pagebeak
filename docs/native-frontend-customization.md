# 原生前端侧栏与目录树验收

日期：2026-10-17。仅本机开发环境，基于已恢复的 Cloudreve 原版页面进行用户明确指定的修改。

后续状态：原生任务看板及账号连接后的自动索引现已实现，见 [最新联动验收](native-sync-and-tasks.md)。本记录保留之前侧栏调整时的版本和独立评审边界。

## 用户要求与结果

| 要求 | 本轮实现 |
| --- | --- |
| 删除视频、音乐、与我共享、我的分享、连接与挂载 | 从原生侧栏移除这五个导航入口 |
| 更换左上角徽标 | 使用已有知序叠纸标识，支持当前深浅主题 |
| 加入目录树 | 复用原生树，显示当前账号真实文件夹，可逐级展开和点击导航 |
| 存储空间移至最下面 | 容量卡片移出目录滚动区，固定在侧栏底部；窄屏侧栏延伸至可视窗口底部 |

“删除”按指令中的动作理解，未移除文件删除或回收站。保留其他原生页面结构与操作。本轮没有把文件夹树替换为知识库语义资料目录，也没有新增账号同步或上传入库逻辑。

## 数据与验收边界

原版页面仍登录独立的非管理员评审账号，四份合成办公材料保留，本轮增加七个合成文件夹用于树验收。没有移动或删除知识库原件，没有把后台共享存储账号交给浏览器，也没有修改个人空间配额。

**Cloudreve 原版上传目前仍不会自动进入知识库**，账号和文件同步尚待后续接入。文件夹树可见不代表知识库同步已完成。
