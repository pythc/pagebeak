## 部署位置与版本

新虚拟机为 `172.22.184.117`，16 个 CPU 线程、约 32 GB 内存。确认 `/dev/xvde` 没有文件系统、分区表或挂载后，创建 ext4 并按 UUID 持久挂载到 `/data`。数据盘容量为 500 GiB，文件系统约 492 GiB。Docker 镜像、文件原件和数据库均存放在数据盘。

系统沿用学校提供的 Ubuntu 20.04，Docker 为 26.1.3；未进行系统跨版本升级。

主目录：`/data/agent-knowledge-base`。首次迁机的源文件发布为 `0.13.5`，763 个发布文件逐项通过 SHA-256 校验。应用镜像由已校验的基础镜像和该版本后端源文件重建，容器内 60 个后端文件与发布清单一致。应用和 WeKnora 分别锁定配置摘要；这不是直接复制旧服务器上的容器数据。

| 组件 | 部署方式与分工 |
| --- | --- |
| 应用 API / Worker | Docker；鉴权、文件解析、版本、整理任务、计算和填写校验 |
| Cloudreve | Docker；每人独立的文件空间、上传、文件管理 |
| WeKnora | 固定源码和外部执行补丁；关键词索引与知识页存储 |

| Office 预览 | systemd broker 调用隔离、无网络的 LibreOffice 容器 |
| HTTPS 入口 | 新虚拟机独立 Caddy；仅代理知序域名 |

数据库、文件服务原生接口和内部 API 均保持回环监听。UFW 保留 SSH 5122，并新增网页入口 80/443；未开放数据库和内部服务端口。Docker 已配置开机启动、容器自动恢复及数据盘挂载依赖，预览服务已启用。未执行整机重启测试。

## 已完成的验证

6. 检索目录，并在另一 MCP 会话中回读相同条目。
7. 将 128000 元换算成 12.8 万元，缺失电话保持空白，填写草稿校验通过。
8. CPU OCR 识别合成中文与金额；Office broker 生成可读中文 PDF。
