33 项回归通过。合成目录使用 WorkBuddy 自带 Python 完成扫描，隔离 WeKnora 中的原等待条目保持同一 ID，版本升为 2；独立请求客户端回读到概览，原始资料和共享清单均为 0 条。0.13.8 缓存能直接升级并回退检索。正式入口和本机已安装助理核对为 0.13.9。真实 WorkBuddy 模型自动执行本轮流程为 `NOT_RUN`，工具只读到了应用窗口外框。下文为初版本机检索的历史记录。

## 用户流程与边界

用户只需要已有的 WorkBuddy、知序教师助理和本人资料空间授权。Skill 随助理提供本机扫描/检索脚本和纯 Python PDF 读取器，调用 WorkBuddy 自带运行环境；不要求教师另装客户端、Python、数据库、OCR 或常驻 MCP 服务。管理员仍需准备校园服务器环境，这和教师安装步骤是两回事。

初始化在当前对话完成，可以合并询问身份、用途和本机目录选择。教师可暂不开启、选择目录，或明确选择个人主目录内全部受支持的非隐藏文档；自动收录重要资料和共享文件清单分别选择。文件正文不是额外授权。

远程 MCP 查云端，本机脚本查教师电脑。两侧结果由 WorkBuddy 联合判断；用于正式知识页、计算或填表的本机原件必须按需收录，随后绑定正式证据和来源版本。用户与 Agent 读取同一知识目录和共享文件清单。WorkBuddy 离线时不做本机扫描或语义整理；服务器原文解析和索引仍运行。

## 实现

- `integrations/workbuddy/weknora-skills/personal-knowledge/scripts/host_documents.py`：标准库 SQLite FTS5、目录白名单、链接排除、增量签名与 SHA-256、Office XML 和文本读取；纯 Python pypdf 随包提供，许可证及 SHA-256 见 vendor.json/pypdf.zip。没有运行时 pip 安装。
- 每个服务地址、知识库和设备独立缓存；文件内容不随目录自动上传。默认不共享清单、不自动收录。撤销范围清除相应正文缓存和搜索索引，原件不删除。
- MCP 新增 `prepare_host_file_upload`、`prepare_host_catalog_sync`、`read_shared_local_catalog`。远程共 35 个工具。MCP 不收本机绝对路径；返回的短期许可只允许指定 SHA-256/大小的文件或指定设备清单，不能读库或调用其他 API。
- 许可有效期 20 分钟；受父连接身份、范围、到期和撤销约束。许可明文只返回一次调用结果，数据库保存摘要；重签使旧许可失效。文件分块断点续传、配额预留、完整哈希核验、完成幂等。脚本拒绝跨源传输和重定向。
- 清单同步与已收录原件的版本观察在同一事务内，冲突回滚。文件变更使旧云端来源/知识页/填写回执失效；人工页保留历史并进入待复核。
- 来源解析使用校园服务器 CPU OCR，不使用教师本机 OCR。Office 文本解析不能保证图表、批注、图片全覆盖；扫描件、旧 Office、超大/加密文件可能只能按名称发现，须按需上传并查看服务端解析结果。

限制：单文件上传仍为 2 GiB，受个人配额限制；本机正文解析预算 128 MiB、50 万字符、每文档 18 秒，PDF 最多40页文本；每轮扫描最多1万份。`complete` 表示枚举是否完成，不表示每份正文完整解析。Windows 尚无实机结果，不能把 macOS 测试宣传成跨平台验收。当前为关键词检索，不承诺向量语义召回。批量内容提取不调用模型，模型消耗来自相关片段阅读、整理、重试和填写。
