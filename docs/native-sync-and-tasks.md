## 页面与操作

原生侧栏“任务进度”打开 `/tasks`，按待处理、处理中、已完成、需处理展示真实后台任务，包含扫描变更、解析索引、目录整理。运行中的任务使用不定进度条；扫描文件显示实际核对数量，不为 OCR 或解析编造百分比。空扫描不占据已完成列表；当前最多返回最近 200 项有意义任务，每列最多展示 12 项。

窄屏增加明确的“上传”按钮，保留“新建”菜单；选中文件显示“删除”。删除仍使用 Cloudreve 原生确认和回收站，不直接清空文件。

拖拽补齐 `dragover.preventDefault()`，区分系统文件拖入和网盘内部移动，修正拖入/离开遮罩计数，并在卸载时移除监听器。4 项事件测试验证可写区域触发上传、内部移动不被拦截、只读区域不上传也不导航离开、卸载清理。**当前自动化工具不允许传入系统拖拽文件，Finder→页面的实际拖拽未完成验收**；按钮上传和原生编辑、删除、恢复有真实浏览器验收，不能混为同一级证据。

## 账号连接

从知识库“我的文件”进入时，签发五分钟一次性连接码，通过 URL fragment 交给原生页面，页面立即移除 fragment。用户确认当前文件空间账号并输入其密码后，服务器核验当前 Cloudreve 身份，建立独立后台会话；不保存密码、不复用浏览器刷新令牌，也不向浏览器交付后台共享存储凭据。

每个知识库最多连接一个原生账号；同一原生账号不能直接绑定另一个知识库。当前页面的非管理员评审账号已连接到隔离的“文件变更验收”知识库，未把合成资料导入其他既有账号。后台会话令牌保存在 Git 忽略的 `secrets/native-sessions/`，文件 0600；会话刷新已实际验证。当前自助连接未支持二次验证账号、断开连接或更换绑定。

原件保留在用户原生空间，知识库记录稳定文件关联、解析证据、哈希及索引。读取时流式下载临时原件，验证大小、SHA-256 和读取前后版本；临时文件随后移除，不再长期保存第二份原件。原生下载域名仅允许当前配置的本机服务，其他对象存储直链尚未纳入这一适配器。

## 两种记录与三个检查点

1. **前端操作报告**：Cloudreve 请求成功后，将操作类型、目标路径、新名称及随机请求 ID 写入按账号隔离的浏览器待发送队列；确认落库才移除，刷新页面后可以补送。后台按请求 ID 幂等，重复请求不会生成多条记录，内容不一致则拒绝。报告标记 `frontend_reported`，不将其当作已核验文件状态或真人身份认证。
2. **服务端文件快照**：后台每 15 秒及收到前端提示时扫描个人目录，分页完整后对账。内容版本变化时流式核验 SHA-256。改名和移动更新关联；内容变化重新解析；连续两次完整扫描都缺失才撤回，以减少扫描期间移动导致的误判。任何扫描失败都不执行缺失删除对账。

三类哈希分别是当前观测文件状态 `current_hash`、完成索引和目录后的 `indexed_hash`、当前访问令牌上次确认的 `agent_observed_hash`。文件状态哈希涵盖稳定 ID、内容 SHA-256、名称、位置、大小和撤回状态；不能只用内容哈希识别改名与删除。

后台完成处理不会推进 Agent 检查点。`agent_change_cursor` 和 `latest_change_id` 让 Agent 即使看到最终 A→B→A 的相同哈希，也能发现中间操作。确认时同时校验最新哈希、历史游标、扫描及索引状态；并发变化返回 409，不覆盖检查点。检查点按访问令牌独立保存，换令牌有独立未读记录。

已解析的历史版本保留 generation 引用，Agent 可分页读取修改前后文本；旧版本显式标记 historical，不用于当前事实或填表。撤回后不返回历史正文。操作发生过但未完成解析的中间版本，不虚构全文差异或原始文件恢复能力。

原生历史来自操作报告和周期观测，不是 Cloudreve 全局不可篡改审计。关闭页面期间尚未发送的报告要等重新打开补送；其他客户端的连续操作可能只观测到最终状态。浏览器缓存清除、服务中断和扫描间隔仍是实际边界。

## Agent 和数据一致性

新增 `get_sync_state`、`read_file_changes`、`read_file_change_content`、`sync_file_changes`、`acknowledge_file_changes`，MCP 共 23 个工具。Skill 已按“检查状态 → 按游标读历史 → 按需比较旧新文本 → 等待整理完成 → 确认检查点”更新。宿主须重连 MCP 重新发现工具；本轮没有修改 WorkBuddy 的现有账号或声称客户端已加载新版 Skill。

后台沿用现有规则分类和原文摘录，不冒充模型语义总结。目录条目和 Source ID 保持稳定，人工标题、摘要、分类、备注保留。内容替换后旧 generation 不参与当前检索，来源支持的旧事实撤回，依赖的页面和表单草稿失效。原生新资料按 reference 收录，不自动认定为本人的履历或科研成果。

知识库配额仍会校验，容量不足则阻止新增索引关联并保留原件。原生空间和知识库的容量账本尚未完全统一，原生配额不会因知识库管理员修改而自动同步。原生软删除的原件仍在回收站，占用按既有记录保留。原生文件暂不通过 MCP 清理方案彻底删除，避免跨系统删除绕过版本和授权；既有知识库私有原件清理流程保留。
