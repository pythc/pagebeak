## 自查修正

1. 解析进程移除服务凭据，限制时间与 CPU；它仍不等于完整 OS 沙箱。
2. 过期 Worker 不能发布；最后一次重试崩溃会进入失败状态。
3. 删除撤回访问，清理原件、证据、源事实及旧值决策、专题、草稿；独立人工声明按其自身来源保留。
4. 资料变化使旧表单草稿失效，不能继续当作最新答案。
5. 快速切换资料丢弃旧响应；移动端有退出入口；退出重载页面，清除旧会话异步状态。失效会话的 401 按已退出处理，其他错误仍提示重试。
6. 固化迁移并禁用破坏性 downgrade；回退应用不能用旧数据库快照覆盖新写入。
7. 保存生成目录不再递增个人事实版本，避免“先生成表单，再整理目录”误使草稿失效；事实确认、原始资料变化和撤回仍保留失效机制。
